# specrig/laravel

specrig for a Laravel 12 or 13 service: the application booted per case, its HTTP
client, queues and console stood in for, and the cases written and approved before
the code.

```bash
composer require --dev specrig/laravel
```

How to lay the harness out and write the cases:
[specrig/specrig-php](https://github.com/specrig/specrig-php#getting-started).

This repository is a read-only copy of `packages/laravel` in specrig-php, kept in
step by specrig-php's release workflow. Issues and changes go to
[specrig-php](https://github.com/specrig/specrig-php).
